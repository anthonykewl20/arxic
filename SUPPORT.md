# Support

If you need help with Arxic, start with this sequence:

1. Read the architecture at `docs/arxic-full-adr.md`.
2. Read current status and slice state in `docs/SYNC.md`.

### Usage questions

Use GitHub Discussions or normal Issues for usage and workflow questions.

### Bug reports

For bugs, use the bug report issue template and include steps, expected behavior,
and environment details.

### Security concerns

For security reports, follow `SECURITY.md` and use private advisory reporting.
