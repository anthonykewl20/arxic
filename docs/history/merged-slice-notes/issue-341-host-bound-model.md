## 3. `CHANGELOG.md` — entry under `## [Unreleased]` → `### added`

```
- issue-341-host-bound-model (#341): the model layer is now transport-agnostic — `ModelAdapterOptions.transport` (default: the existing HTTP client, byte-identical) lets the adapter bind to a locally installed agent CLI (Claude Code, Codex CLI, opencode, or any stdin/stdout executable) via `ARXIC_MODEL_PROVIDER=host-cli` + `ARXIC_MODEL_HOST_CLI`, without requiring `ARXIC_MODEL_BASE_URL`/`ARXIC_MODEL_API_KEY`. Host-bound runs always record zero tokens and carry an explicit `provider: 'host-bound'` marker on the run record so they are never mistaken for a metered API call that happened to cost nothing; the pre-call budget estimate is pinned to an explicit zero price for this path rather than falling through to `resolveModelPrices`.
```
