## 7. Honest deferrals and decisions (recorded, not hidden)

1. **Directory rename deferred.** Package renamed `@arxic/domain-inventory-spike` → `@arxic/domain-inventory`, but the directory stays `packages/domain-inventory-spike`: DG-05's lockstep guard (`packages/source-ua-adapter/src/__tests__/interchange-lockstep.test.ts`) imports this package's interchange types via a RELATIVE path, and `packages/source-ua-adapter` is DG-10-owned this wave. The directory move is a one-line follow-up to be landed atomically with that import's update.
2. **Frozen JSON Schema for the interchange: still deferred** (DG-02 §4 deferred it to DG-05; DG-05 shipped the TS shape + real validator instead). DG-06 keeps that posture deliberately: a frozen schema needs its own contract process (ADR §10), and the enforced spec today is the TS shape + fail-closed `validateInterchange` + the DG-05 compile-time lockstep guard + DG-06's translator integration tests. Revisit when a non-TypeScript producer appears.
3. **`apps/worker` StageId mirror is a CI-gate blocker outside this slice's ownership.** `apps/worker/src/run-spec.ts:28` mirrors the orchestrator `StageId` union; stage 13 requires the mirror to gain `| 13` (one line, plus nothing else — runtime worker suite is green 39/39). Flagged on #250 (comment 5309645108). This note's author did NOT touch `apps/**`.
4. **Double source scan.** Stage 13 calls `collectRouteInventories()` which re-scans the tree stage 1 already scanned (the frozen seam has no cached combined call; the NormalizedSourceIndex shape must not change). Deterministic and correct, ~2× scan cost; optimization deferred to a dedicated seam change.
5. **Evidence-graph composition is caller-side.** `buildInventoryEvidenceGraph` builds its own container (like `buildStaticEvidenceGraph`); merging both into one graph is a caller concern (attribute-conflict policy still to be designed).
6. **Consumer-surface semantics tension (documented, intentional).** Canonical `surfaceKind` marks every GET-servable surface `page`; the DG-04 consumer's `surface` distinguishes UI file conventions from program routes by extractor. The projection preserves the CONSUMER semantics verbatim (extractor-based) so proposal batching does not change semantics when it switches to the real inventory. A Laravel GET web route is canonically `page` but consumer-`route`.
7. **Estimate vs actual.** BookStack `routes/web.php` include: gap estimated 260 routes, 257 actually in the interchange (the estimator parses the included file with a simpler counter). The resolution records both fields; divergence is visible, not reconciled.
8. **koel channels.php include.** Resolves only when a provable empty group context exists; by policy it stays a visible 0-route gap (conservative — a wrong empty prefix would fabricate unprefixed collisions).
