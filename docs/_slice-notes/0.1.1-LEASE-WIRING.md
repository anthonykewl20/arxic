## 5. Evidence pointers

- Real-world proof: `packages/orchestrator-langgraph/src/__tests__/exploration-real-world.test.ts` — real Chromium drives the reference auth app through leased reversible fill/click actions with sanitized timeline provenance and named screenshots.
- Artifacts: test-local sanitized timeline provenance and screenshots are intentionally ephemeral; no raw trace ZIP is retained.
- Gates: `pnpm lint`, `pnpm typecheck`, `node scripts/license-gate.mjs`, targeted orchestrator/policy suites (150 tests), and full `pnpm test` (117 files, 1025 tests) passed. Final format output: `All matched files use Prettier code style!`
- Red-first evidence: `resets and releases stage-7 leases after a failed run` persists a terminal failed state, then invokes a new orchestrator sharing the coordinator. The guard is directly observable: without the terminal-state condition in `#rehydrateFixtureLeases`, the persisted stage-7 lease is re-registered and the asserted reset/release counters become two rather than one. The test's exact-once and subsequent-`prepare()` assertions therefore fail against that counterfactual; the production guard was not temporarily removed to avoid a non-atomic source mutation.
- Cleanup semantics: observed `ARXIC-FIXTURE-RESET-FAILED` or `ARXIC-FIXTURE-RELEASE-FAILED` warnings are appended and persisted after the terminal result is formed, without adding a duplicate stage checkpoint or revising truth/promotion. `release()` is reset-then-release.
- Residuals: the default lease is five minutes and nonterminal rehydration renews it, but renewal does not shorten an already-issued later expiry. Cleanup is process-local best effort: there is no out-of-band reaper, so a hard kill during awaiting-approval leaves provider fixtures until a later run rehydrates. A failed provider release poisons `#outstanding` if that coordinator is reused (tracked follow-up; out of slice scope). One selected lease authorizes all reversible steps; this pre-existing `PolicyEngine` shape is now load-bearing. `PolicyEngine`'s internal `Date.now()` is not injectable through its current API.
