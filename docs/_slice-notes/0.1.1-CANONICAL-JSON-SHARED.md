## 7. Regressions caught and fixed during the slice

- The worker Docker promotion test exposed a wire-byte compatibility regression: the original worker serializer ordered object keys with `localeCompare`. The worker result and source-tree paths now explicitly select legacy locale ordering while new callers retain strict codepoint ordering. A comment-only edit to the generated standalone screenshot runtime also changed its attested digest across the worker/host boundary; that edit was removed rather than weakening provenance validation.
- The paused-lease resume test exposed policy authorization reading ambient wall-clock time instead of the Action-owned replay clock. `PolicyEngine` now passes its supplied clock through the policy input, so an expired persisted lease is renewed deterministically before exploration resumes.

## 8. Documented structural-gate deferrals and residuals

- `packages/policy-engine/src/snapshot.ts` keeps `stableStringify`: policy snapshot normalization is domain-specific; its `timestamp` remains wall-clock non-decision metadata.
- `packages/playwright-agent-adapter/src/exploration-driver.ts` keeps `stableStringify`: accessibility evidence serialization has domain-specific redaction semantics.
- `packages/bundle-promoter/src/bundle-assembler.ts` keeps `canonicalizeSbom`: CycloneDX redaction, volatile-field removal, and array ordering are domain-specific.
- `computePolicySnapshot` input SHA-256 becomes time-dependent when a clock is injected; this is benign today because it is shape-checked only and never golden-compared.
- Worker `keyOrder: 'locale'` is pinned by `apps/worker/src/source-tree-hash.test.ts` and ASCII-stable for current keys; cross-ICU ordering divergence remains a theoretical residual.
- Ast-grep escape diagnostics now say `Path escapes source root.` instead of `Path escapes resolved source root.`; the blocked outcome and containment semantics are unchanged, and wording is unified.
