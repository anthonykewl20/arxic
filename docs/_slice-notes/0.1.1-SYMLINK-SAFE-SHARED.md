## 7. Regressions caught and fixed during the slice

- The worker Docker promotion test exposed a canonical wire-byte compatibility regression: the original worker serializer used locale key ordering. The worker result and source-tree paths now use the shared helper's explicit legacy locale mode; a comment-only change to the generated screenshot runtime was removed because it changed the cross-boundary attested digest.
- The paused-lease resume test exposed policy authorization using ambient wall-clock time rather than the Action-owned replay clock. The policy engine now forwards its injected clock, allowing an expired persisted lease to renew before exploration continues.
