## 5. Evidence pointers

- Real-world proof: `apps/worker/build-and-verify.sh` and `packages/environment/src/__tests__/worker-image.real-world.test.ts` — real Docker worker image, Chromium, native modules, and internal Docker networking.
- Artifacts: command output is retained in the lane hand-off report; no Playwright trace ZIPs are retained.
- Gates: typecheck passed · lint passed · format passed · test (1010 passing) passed · license gate passed (0 rejected).
- Deferred: `packages/environment/src/worker-sandbox.ts` still has the separate `node:20-alpine` default; it is outside this lane and remains for its owning lane.
- Deferred cost: `worker-image` builds inline (`COPY . .`, frozen install, and Chromium) at billed-minutes cost for every worker-relevant PR; it is intentionally not cached or prebuilt.
- Known residual: the conservative filter deliberately excludes worker-adjacent `packages/contracts`, `packages/source-ua-adapter`, `packages/playwright-agent-adapter`, and `test-fixtures/**`. A toolchain-breaking change confined there will not run `worker-image`; the always-run required `ci` job remains the safety net while this non-required job stays cheap.
- `workflow_dispatch` runs `worker-image` only when the dispatched ref diverges from `origin/main` on a worker-relevant path; dispatching `main` has `merge-base == HEAD`, no diff, and skips it.
