## Post-red test refinements (disclosed, no assertion loosened)

Between the red runs above and green, the journey test was refined twice:

1. The first red iteration set `noise = true` but forgot to reset `changed = false`, so the
   noise run captured the big-flip page and measured 445,697 changed pixels. Fixed before
   implementation; the honest measured mutation is 64 changed pixels (ratio 1.33e-4).
2. The raised-gate save changed from `visualChangeRatio: 0.005` to
   `visualChangeRatio: noiseCapture.ratio` (the exact measured ratio) so the journey pins the
   STRICT `ratio > gate` boundary: at gate == measured ratio the capture is 'unchanged'
   (strict-gate sad-path row), and any gate above the measured ratio follows a fortiori.
   The red-phase failure reason ('Unknown project setting' at saveProject) is identical for
   both versions; `changedPixels > 0`, diff-file and diff-region retention assertions are
   unchanged. A debug-only artifact dump used to diagnose (1) was removed before green.
