- **Population:** every retained PNG under `docs/evidence/WEB-402-*` — **344 files**.

## What the pre-pass looked for

Credentials, API keys and tokens, email addresses, session or cookie data,
personal information, and anything else not intended for public retention.

## Result

**No credential, token, API key, session value or personal datum was observed
in any of the 344 screenshots.** Capture-time masking is visibly applied and
consistent: administrator-token inputs, email/password/reset-token fields and
declared identity regions render as solid mask blocks, and secret configuration
fields render **environment-variable reference names** (`ARXIC_SECRET_MODEL_KEY`,
`ARXIC_SECRET_TEST_EMAIL`, `ARXIC_SECRET_TEST_PASSWORD`) rather than values.
Workspace paths are per-run temporary directories (`/tmp/arxic-source-ua-*`) in
every lane **except** the two recorded below.

## Findings (both `observed`, neither is a credential)

### F1 — Operator home-directory path rendered in workspace screenshots

The project card and the Administration page's "Allowed project roots / Server
workspace" field render the absolute workspace path. In two lanes that path is
the operator's real home directory rather than a temp dir:

- `docs/evidence/WEB-402-INSTALL/` — `01-fresh-install.png`, `02-graceful-restart.png`, `03-crash-recovery.png`
  (`/home/<operator>/devtony/arxic/.worktrees/clean-server-402/test-fixtures/vulnerable-auth-app`)
- `docs/evidence/WEB-402-DASHBOARD-UX/` — the `*-admin.png` captures at every
  breakpoint/theme (`/home/<operator>/devtony/arxic/.worktrees/dashboard-production`)

This publishes the operator's OS username and local directory layout in a public
repository. It is not a secret, but "anything not intended for public retention"
is the gate's own wording, and the gate says to fail on any doubt. **Owner
decision required** — remediation of already-published evidence is a history
question, not a file question.

### F2 — The same path is repo-wide, and two source defaults emit it

`git grep -l "/home/<operator>"` matches **305 tracked files** — retained run
JSON under `docs/evidence/DG-11` and `DG-12`, README/manifest docs, 17 non-PNG
files under `docs/evidence/WEB-402-*`, and two source files whose *defaults*
embed the path:

- `apps/web/src/__tests__/visual-koel-login.real-world.test.ts`
- `apps/web/src/compact-visual/corpus-capture.ts`

Both read `process.env.ARXIC_VISUAL_THIRD_PARTY` first, so this is not a
portability break — but the fallback publishes the path. The two source defaults
are fixed in this slice (`homedir()`-derived, behaviour-identical on the
operator's machine, no username in the source). The 303 evidence/doc occurrences
are left as an owner decision, recorded here rather than silently rewritten.

## What a human still has to do

Everything in `docs/release-gates/screenshot-inspection.md` steps 2-6. This
pre-pass replaces none of it. Specifically it does **not**:

- certify any pixel secret-free (an LLM cannot, per the gate's own boundary);
- inspect at native resolution — contact sheets downscale 1025x712 captures to
  roughly half-scale, so sub-pixel or very small text could be missed;
- cover evidence roots outside `docs/evidence/WEB-402-*` (the wider
  `docs/evidence/` tree holds 1,460 PNGs in total);
- decide F1 or F2.

## Reproducing it

repo (a screening aid that decides nothing). It is **not** committed: adding a
tool to `scripts/` requires the charter's test bar, and this slice did not build
that. Recorded follow-up: port the tiler to Node/`sharp` with a deterministic
sheet-count/dimension test, then wire it into `scripts/inspection-manifest.mjs`
as an optional pre-pass artifact.
