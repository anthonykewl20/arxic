=== 5. Test-side determinism fix disclosed (no assertion widened, no implementation change) ===

The drift journey in campaign-recurrence.real-world.test.ts failed twice under a contended
regression batch ("expected 2 campaigns, got 3") and passed in isolation and in earlier runs with
identical code. Root cause (test-side, confirmed by an instrumented probe run): with a
'*/1 * * * *' schedule, the first real engine run can straddle the minute boundary; the
Workbench's own 1s background tick then legitimately fires that slot mid-idle, and the test's
subsequent explicit tick fires the NEXT slot — two legitimate fires where the journey assumed
one. Fix: both recurring journeys (drift stop and row history) now arm with '0 0 1 1 *' (next
January 1 — unreachable by the background ticker within a test lifetime) and drive every fire
with explicit wb.tick(slot) calls; slot coalescing is still proven by ticking the same slot
twice. Every assertion is unchanged in strength; the implementation was never touched for this.
