# Arxic

Arxic is an evidence-driven behavioral intent compiler for authentication-oriented TypeScript applications. It assembles validated static and runtime signals into independently replayable Playwright workflow bundles, with explicit evidence, replay provenance, and deterministic promotion gates.

Status: Proposed, pre-MVP

## Repo map

- `docs/arxic-full-adr.md` (authoritative architecture decision record)
- `gears/` (upstream engines and provenance records)
- `apps/` and `packages/` (monorepo implementation layers)
- `rulepacks/` (framework behavior rule directories)
- `schemas/` (frozen schema artifacts)
- `test-fixtures/` (reference applications)
