### added

- M1-02 Crawlee breadth surface map (#16): `@arxic/crawlee-adapter` adapts a real Crawlee 3.18 `PlaywrightCrawler` (Playwright pinned to 1.62.1) behind the frozen `SurfaceDiscoverer` contract to perform bounded **breadth** surface discovery (NOT workflow verification). It enumerates routes, titles, forms, controls, and same-origin navigation edges within caller-supplied `origin`/`maxUrls`/`maxDepth` budgets and yields runtime `EvidenceRef`s + frozen `Diagnostic`s through `discover()`. ADR §7.4 prohibitions are enforced as fail-closed policy at BOTH the inventory and network layers: destructive forms are observed but **never submitted** (`ARXIC-SURFACE-002` `blocked`), and same-origin non-safe HTTP methods (anything but `GET`/`HEAD`/`OPTIONS`) are aborted via request interception so page-JS-initiated mutations (`fetch` POST, `sendBeacon`, JS form-submit) cannot mutate state during discovery (`ARXIC-SURFACE-008` `blocked`); cross-origin browser requests are aborted via request interception and cross-origin WebSockets are closed before connect (`ARXIC-SURFACE-001` `blocked`); workflows sharing a mutable persona are serialized through a per-identity mutex (`ARXIC-SURFACE-004` `blocked`); frontier growth past `maxUrls`/`maxDepth` terminates safely (`ARXIC-SURFACE-003` `blocked`); transient HTTP 408/425/429/≥500 retries then gives up bounded as `observed`, never `verified` (`ARXIC-SURFACE-005`). Runtime `EvidenceRef`s are withheld unless a valid same-origin attested build digest is available (`ARXIC-SURFACE-007` `blocked`) and invalid origins are rejected up front (`ARXIC-SURFACE-006`). Canonical `serializeSurfaceMap` JSON is byte-identical for fixed runtime inputs; `navigationEdges` are deduped (shallowest `depth` kept) and totally-ordered by `from`/`to`/`status`/`reason`/`depth` so serialization stays byte-stable under concurrency. Real-world proof runs the real `PlaywrightCrawler` against the REAL `reference-auth-app` in real Chromium within budgets, proves `/`, `/login`, and `/forgot-password` surfaces carry real runtime evidence, and proves the mutation budget (sqlite `users`/`reset_tokens`/`sessions`/`mfa_challenges`) is byte-for-byte unchanged after the crawl. The frozen §10 contracts are unchanged; the adapter-local `SurfaceMap`/`RouteSurface`/`NavigationEdge` types bridge to the frozen `EvidenceEvent`. The engine-upgrade contract suite is gated by ADR §23.14.
- M1-01 Static inventory + evidence graph (#15): `@arxic/evidence-graph` is a Graphology-backed service container that ingests static evidence into a typed, content-addressed graph (ADR §8.4). Node kinds (Repository/Revision/File/Symbol/Config/Route/Endpoint/UiSurface/Control/Handler/Guard/Validator/Document/RuntimeSurface) and edge kinds (contains/revises/defines/imports/calls/renders/handles/guards/validates/configures/exposes) are enforced. **Output-influencing edges require ≥1 `EvidenceRef` at both compile time (non-empty tuple) and runtime** (rejected with `ARXIC-GRAPH-001` `blocked`); conflicting node/edge structure surfaces as `ARXIC-GRAPH-002`/`ARXIC-GRAPH-003` `contradicted`. The frozen `EvidenceEvent` carries no graph semantics, so a local `GraphIngestEvent` bridges it without modifying the frozen §10 contracts; `buildStaticEvidenceGraph` consumes the richer `NormalizedSourceIndex` + `AstGrepScanResult` (`.matches`/`.chains`) to connect `route --handles--> handler --guards--> guard`. Canonical sorted JSON/JSONL is byte-identical across runs before timestamps (property test + real-fixture rebuild), and SHA-256 content-addressed. Real-world proof builds the graph from both REAL fixture apps with real Tree-sitter + real `sg`, proving the `/login` route→handler→guard chain carries ≥2 real source EvidenceRefs per edge. Disposition classification remains deferred to the orchestrator (#17) and reconciler (#18).
- M0-EXIT vertical gate (#14): `@arxic/m0-pipeline` composes stage 0 target attestation, stages 1–3 committed ast-grep login evidence, stage 9 Workflow-to-Playwright compilation, stage 10 deterministic two-pass clean-fixture verification in real Chromium, and stage 12 atomic promotion. The verifier alone assigns `verified`; split runs are `contradicted` with flaky diagnostics, all-failed runs are `contradicted` as app defects, and missing runtime evidence is `blocked`. Promoted bundles carry screenshots, traces, spec, hashes, NOTICE, provenance, and a validated manifest; real end-to-end proof independently recomputes hashes and preserves the second last-known-good bundle after an injected third-run source-evidence failure. M0 exit criteria are met; the `0.1.0` release remains pending, so `VERSION` stays `0.0.0`.
- M0-15 PREFLIGHT target-attestation acceptance (#44): `@arxic/environment` now composes its existing live handshake across target sets, accepts both real reference apps as `local-test`, refuses production-styled and missing or malformed attestations with blocked diagnostics, and writes deterministic canonical run-artifact JSON recording every target decision. Artifact write failures fail closed with a loop-closed `ARXIC-ATTESTATION-ARTIFACT-WRITE-FAILED` diagnostic.
- M0-14 policy engine (#41): `@arxic/policy-engine` provides fail-closed authorization over a closed registry of navigation, form-submit, fixture-change, file-write, promotion, and delete-user actions mapped to the four ADR §16.4 action classes. Every action requires an exact origin allowlist match; reversible mutations require caller-supplied valid lease state; external side effects require sandbox execution plus recorded exact action-and-origin approval; destructive actions require recorded exact action-and-origin approval; and unknown/injection actions or caller class conflicts are denied. Every result records a decision and deterministic policy snapshot with SHA-256 over canonical inputs. Stable `ARXIC-POLICY-*` diagnostics loop-close through the frozen validator, and real reference-auth-app attestation data proves the authorization boundary.
- M0-13 ModelAdapter spike (#40): `@arxic/model-adapter` owns all model-provider mechanics so agent nodes never see raw credentials or prompt retention; credentials resolve at call time and appear only as a `Bearer` header; every structured-output request is schema-bound and validated by real AJV before any downstream action; invalid output retries then blocks with `ARXIC-MODEL-RETRIES-EXHAUSTED` and no promotion (the truth-state decision stays in orchestration, M1 #42); schema-version drift fails closed; model output is content-as-data (injection blocked without policy mutation); the run record carries only request id, schema version/hash, model, token/cost, timestamp, and provider retention/region/source-sharing metadata—never prompt bytes—and a redaction gate fails the run if credential or prompt bytes enter emitted artifacts. Stable `ARXIC-MODEL-*` diagnostics loop-close through the frozen validator. A real local `node:http` OpenAI-compatible endpoint plus real AJV prove the wire format, retry-then-blocked no-promotion, injection-as-data, schema drift, credential/prompt redaction, the closed run-record shape, and Bearer-only credential handling.
- M0-11 threat model + target-attestation check (#12): `@arxic/environment` now performs a real bounded stage-zero attestation fetch, validates target shape, exact origin, environment class, nonce, and optional HMAC-SHA256 build receipt, refuses production-looking targets by default, permits overrides only from well-formed static recorded human approvals, and always emits a versioned decision record plus frozen-contract diagnostics. The new worker threat model specifies isolation, content-is-data prompt-injection defenses, action boundaries, secret/PII redaction, and trusted-control-plane-only Docker/Testcontainers orchestration with an accepted host-service local-development mode.
- M0-10 atomic promotion + last-known-good spike (#11): `@arxic/bundle-promoter` now deterministically freezes staged bundles, validates frozen manifests, independently re-reads and SHA-256 verifies private same-directory staging bytes, checks byte counts internally, serializes concurrent writers with an exclusive lock, snapshots the prior public bundle to `.lkg`, and atomically renames staged bytes into place. Stable blocked diagnostics, frozen-interface contract gates, and real filesystem proof cover failed gates, malformed manifests, hash mismatch, lock contention, injected pre-replace failure, independent receipt-hash recomputation, deterministic bytes, and last-known-good preservation without extending the frozen receipt.
- M0-09 Playwright agent handshake + fallback spike (#10): `@arxic/playwright-agent-adapter` exactly pins Playwright Test 1.62.1, negotiates and fail-closed validates the hidden MCP stdio server's nine-tool contract, translates list/run calls, rejects unsafe healer proposals, and deterministically compiles frozen Workflow IR into a direct Chromium fallback. Contract, process-injection, and real-world tests prove the real agent handshake plus real login execution and fallback list/run against the reference app.
- M0-08 ast-grep rulepack spike (#9): `@arxic/ast-grep-adapter` now owns its ast-grep 0.45 runtime dependency, executes the real CLI across caller-selected versioned Next.js and Express auth packs, validates metadata and conflicts fail-closed, emits committed/hash-linked frozen-contract evidence, labels regex fallback without manufacturing evidence, and advisory-connects route → handler → guard. Per-rule positive/negative fixtures and real fixture-app tests cover auth forms, guards, password/token/mail/session/TOTP evidence and locale-independent deterministic output.
- M0-07 Understand-Anything subset extraction spike (#8): `@arxic/source-ua-adapter` now resolves full Git commits, creates deterministic raw-byte SHA-256 manifests, detects dirty/shallow/no-commit and bounded-file gaps, and uses real native Tree-sitter TypeScript/TSX/JavaScript/JSX grammars to emit frozen-contract source evidence for symbols, imports, calls, Next.js App Router routes, and Express routes. Dirty bytes never receive committed provenance. Canonical normalized output is byte-identical before its explicit timestamp; real fixture-app integration tests, grammar-license checks, diagnostic loop closure, and the ADR §23.14 `SourceIndexer` engine-upgrade contract gate cover the seam.
- M0-06 License gate + SBOM automation (#7): `scripts/license-gate.mjs` scans the real pnpm dependency graph against a permissive allowlist (MIT/Apache/ISC/BSD/0BSD/CC0/Python/BlueOak/WTFPL/Unlicense + weak-copyleft **MPL-2.0/LGPL** as a documented policy extension — the issue names only GPL/AGPL/SSPL as rejected) and REJECTS GPL/AGPL/SSPL/Commons-Clause/BSL/EUPL/CC-BY-SA/PolyForm/Unknown. `license-exceptions.json` holds justified detection-overrides (`thirty-two` → MIT upstream; pnpm mis-detects it). TDD sad-paths (AGPL/GPL/SSPL/Unknown rejected; **LGPL allowed — explicitly distinguished from GPL**; exceptions honored) + a **real-graph assertion** (0 rejected on the live Arxic graph — goes red if an AGPL dep is added).
